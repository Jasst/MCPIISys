# Local AI Assistant

Автономный self-hosted ИИ-ассистент: LLM через LM Studio, долговременная память
(граф знаний, эпизоды, цели, противоречия), веб-поиск, генерация изображений
через EasyDiffusion, инструменты через MCP.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

Документация API: http://127.0.0.1:8000/api/docs

## Требования

- LM Studio с запущенным сервером (адрес задаётся в `GCN/config_ai.py`).
- EasyDiffusion (необязательно, для генерации изображений).

## Структура

- `run.py` — запуск uvicorn (один воркер: память хранится в процессе).
- `main.py` — FastAPI-приложение, lifespan, middleware.
- `routes/ai_assistant.py` — API `/ai/*`: чат со стримом, поиск, генерация, память.
- `mcp_server_blockcoin.py` — MCP-инструменты памяти, поиска и изображений.
- `GCN/` — ядро: LLM-клиент, память, маршрутизация инструментов, автономность.
- `config.py` — настройки сервера; `GCN/config_ai.py` — настройки ИИ.

## Важно

Один воркер обязателен: состояние ассистентов и сессии хранятся в памяти процесса.
Данные памяти лежат в `../ai_memory_v3` относительно папки проекта.

## Интерфейс

Открой http://127.0.0.1:8000/ — это чат. Слева список чатов с группами по дате и поиском,
справа сам чат. Внизу переключатели «Фото», «Поиск», «Рассуждения».
Настройки (кнопка внизу слева): отправка по Enter, размер текста, компактный режим,
уведомления ассистента, экспорт и удаление локальных чатов.

Проверить логику интерфейса без браузера: `cd tests/ui-smoke && npm install && npm test`.

## Запуск через Docker (nginx) и start_app.bat

Схема: nginx в Docker слушает 80/443 и проксирует на порт 8000 хоста,
где работает `python run.py`.

1. Положи `nginx.conf`, `docker-compose.yml` и `start_app.bat` в папку проекта.
2. Сертификаты TLS — в `C:\nginx\ssl` (файлы `blockcoin.ru-chain.pem` и `blockcoin.ru-key.pem`).
   Домен в `nginx.conf` поменяй на свой (обозначено комментарием).
3. Запусти `start_app.bat` и выбери пункт 1.

Без nginx можно работать напрямую: `python run.py` и открыть http://127.0.0.1:8000/.

## Вход и регистрация

Вход по email и паролю. На странице `/login` три вкладки: «Вход», «Регистрация», «Восстановление».

- **Регистрация**: email и пароль, на почту приходит 6-значный код. После ввода кода аккаунт подтверждён и ты сразу входишь.
- **Восстановление**: email, код на почту, новый пароль. Смена пароля выбрасывает все старые сессии.
- **Коды**: действуют 10 минут, после 5 неверных попыток сгорают, новый код можно запросить раз в 60 секунд. В базе хранится только хеш кода.
- **Пароли**: хранятся в виде scrypt-хеша. Блокировка на 15 минут после 5 неверных попыток входа.

Настройка почты: в `.env` задай `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`. Подходит любой провайдер с SMTP (Gmail, Яндекс, Brevo, Resend и т.п.). Для проверки без почты поставь `AUTH_DEV_MODE=1`: коды будут печататься в `assistant.log`. В продакшене этот флаг должен быть 0.

Перед запуском для интернета задай постоянный `SECRET_KEY` (32+ символов), иначе все сессии сбрасываются при перезапуске. Пользовательская база лежит в `auth.db` рядом с `run.py`: её нужно бэкапить.

Если раньше использовал `local_user` и хочешь сохранить его память, после первой регистрации переименуй папку `ai_memory_v3/local_user` в `ai_memory_v3/u1` (номер в имени — id пользователя в базе).

Локальный режим без входа: `AUTH_DISABLED=1` (только для своей машины).

## Доступ из интернета и подключение внешнего ИИ

1. Настрой почту и `SECRET_KEY` (см. выше), укажи домен в `MCP_PUBLIC_HOSTS=blockcoin.ru`, `FLASK_ENV=production`.
2. Перезапусти приложение. Зарегистрируйся на `https://домен/register` и войди.
3. В настройках чата нажми «Получить код» в разделе «Внешний ИИ (MCP)».
4. Во внешнем клиенте добавь MCP-сервер `https://домен/mcp/` (см. `external/`).
5. В разговоре скажи внешнему ИИ: «войди с кодом ...». Он вызовет `login` и получит доступ к памяти этого аккаунта.

Код привязан к аккаунту. Новый код отключает все прежние подключения внешних ИИ.
