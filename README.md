# Local AI Assistant

Автономный self-hosted ИИ-ассистент: LLM через LM Studio, долговременная память
(граф знаний, эпизоды, цели, противоречия), веб-поиск, генерация изображений
через EasyDiffusion, инструменты через MCP.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

Документация API: http://127.0.0.1:8000/api/docs

## Требования

- LM Studio с запущенным сервером (адрес задаётся в `GCN/config_ai.py`).
- EasyDiffusion (необязательно, для генерации изображений).

## Структура

- `run.py` — запуск uvicorn (один воркер: память хранится в процессе).
- `main.py` — FastAPI-приложение, lifespan, middleware.
- `routes/ai_assistant.py` — API `/ai/*`: чат со стримом, поиск, генерация, память.
- `mcp_server_blockcoin.py` — MCP-инструменты памяти, поиска и изображений.
- `GCN/` — ядро: LLM-клиент, память, маршрутизация инструментов, автономность.
- `config.py` — настройки сервера; `GCN/config_ai.py` — настройки ИИ.

## Важно

Один воркер обязателен: состояние ассистентов и сессии хранятся в памяти процесса.
Данные памяти лежат в `../ai_memory_v3` относительно папки проекта.

## Интерфейс

Открой http://127.0.0.1:8000/ — это чат. Слева список чатов с группами по дате и поиском,
справа сам чат. Внизу переключатели «Фото», «Поиск», «Рассуждения».
Настройки (кнопка внизу слева): отправка по Enter, размер текста, компактный режим,
уведомления ассистента, экспорт и удаление локальных чатов.

Проверить логику интерфейса без браузера: `cd tests/ui-smoke && npm install && npm test`.

## Запуск через Docker (nginx) и start_app.bat

Схема: nginx в Docker слушает 80/443 и проксирует на порт 8000 хоста,
где работает `python run.py`.

1. Положи `nginx.conf`, `docker-compose.yml` и `start_app.bat` в папку проекта.
2. Сертификаты TLS — в `C:\nginx\ssl` (файлы `blockcoin.ru-chain.pem` и `blockcoin.ru-key.pem`).
   Домен в `nginx.conf` поменяй на свой (обозначено комментарием).
3. Запусти `start_app.bat` и выбери пункт 1.

Без nginx можно работать напрямую: `python run.py` и открыть http://127.0.0.1:8000/.
