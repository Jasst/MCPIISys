# Smoke-тест интерфейса ИИ-чата

Проверяет логику `static/js/ai-app.js` в DOM (jsdom): отправка, потоковый ответ,
копирование, повтор, остановка, переименование, экспорт, вложения и настройки.

```bash
cd tests/ui-smoke
npm install
npm test
```

Тест не проверяет вёрстку: для этого нужен реальный браузер.

`generation.js` проверяет фоновую генерацию: переключение чатов во время ответа,
блокировку отправки в другом чате, восстановление ответа после перезагрузки
(через /ai/chat/attach и /ai/chat/last_response) и остановку (/ai/chat/stop).
